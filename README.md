# Инструкция по начальной настройке программы

## Общая информация

Данная инструкция описывает порядок настройки информационной базы для использования новой функциональности по управлению абонентским обслуживанием, планированию работ специалистов, расчету заработной платы и формированию отчетности.

## Предварительные требования

- Конфигурация должна быть обновлена до версии с реализованными доработками
- Пользователи должны иметь соответствующие права доступа для выполнения настроек

## 1. Настройка констант

### 1.1. Константы для интеграции с Telegram

|---------------------------------|-------------------------------------|-----------------------------|
| Токен управления телеграм ботом | Токен для управления Telegram-ботом | Получить у @BotFather       | 
| Телеграм группа                 | ID группы/чата для оповещений       | Получить через Telegram API |

### 1.2. Константы для документооборота
**Расположение:** Обслуживание клиентов → Сервис

|            Константа            |               Назначение            |                   Значение                  |
|---------------------------------|-------------------------------------|---------------------------------------------|
| Номенклатура абонентская плата  | Номенклатура для абонентской платы  | Ссылка на элемент справочника Номенклатура  |
| Номенклатура работы специалиста | Номенклатура для работ специалиста  | Ссылка на элемент справочника Номенклатура  | 

### 1.3. Константы для планировщика
**Расположение:** Администрирование → Сервис

|       Константа     |                   Назначение                      | Значение |
|---------------------|---------------------------------------------------|----------|
| Начало рабочего дня | Меняет время начала таблицы на начальной странице | Время    |

## 2. Настройка ролей и прав доступа

### 2.1. Назначение ролей существующим пользователям

|         Профиль      |       Роли        |                    Назначение                  |
|----------------------|-------------------|------------------------------------------------|
| Специалист           | Специалист        | Специалисты, выполняющие работы у клиентов     |
| Менеджер             | Менеджер          | Менеджеры, планирующие работы специалистов     |
| Бухгалтер И.Т. фирмы | БухгалтерИТФирмы  | Бухгалтеры, формирующие акты и отчеты          |
| Кадровик расчетчик   | КадровикРасчетчик | Сотрудники отдела кадров и расчетчики зарплаты |

### 2.2. Порядок настройки:
1. Открыть Администрирование → Настройки пользователей и прав → Пользователи
2. Выбрать нужного пользователя → Права доступа
3. Назначить соответствующий профиль группы доступа

## 3. Настройка справочников

### 3.1. Справочник "Договоры контрагентов"
**Расположение:** Обслуживание клиентов → См. также

- В перечислении "ВидыДоговоровКонтрагентов" добавлен вид "Абонентское обслуживание"
- Дополнительные реквизиты для договоров абонентского обслуживания:
  - ДатаНачалаДействия
  - ДатаОкончанияДействия 
  - СуммаАбонентскойПлаты
  - СтавкаЧасаРаботы

### 3.2. Справочник "Номенклатура"
**Расположение:** Покупки и продажи → Справочники

- Создать элементы номенклатуры для:
  - Абонентской платы (указать в константе)
  - Работ специалиста (указать в константе)

## 4. Настройка организационных моментов

### 4.1. Настройка сотрудников
1. В справочнике "Сотрудники" для специалистов установить:
   - Категорию сотрудника "Специалист"
   - В регистре сведений "Условия оплаты" установить оклад и процент от работ

### 4.2. Настройка договоров
1. Для существующих клиентов создать договоры с видом "АбонентскоеОбслуживание"
2. Заполнить в договорах:
   - Период действия
   - Сумму ежемесячной абонентской платы
   - Ставку часа работы специалиста

## 5. Настройка расчетных механизмов

### 5.1. Настройка планов видов расчета (ПВР)
**Расположение:** Расчет заработной платы → Настройка

|     План видов расчета    |                    Назначение                 |
|---------------------------|-----------------------------------------------|
| Основные начисления       | Для расчета окладов и процентов от работ      |
| Дополнительные начисления | Для расчета отпускных и фмксированных премий  |
| Удержания                 | Для удержания НДФЛ                            |

**Действия:**
- Настроить основные виды расчетов в каждом ПВР (Оклад, ПроцентОтРабот, Отпускные, НДФЛ)
- Настроить зависимости между видами расчетов

### 5.2. Настройка условий оплаты сотрудников
**Расположение:** Расчет заработной платы → Обычные → Условия оплаты

Для каждого сотрудника установить:
- Оклад (для всех сотрудников)
- ПроцентОтРабот (только для специалистов)

## 6. Тестирование функциональности

### 6.1. Тестирование создания заявок на обслуживание
1. Создать документ "Обслуживание клиента"
2. Проверить:
   - Корректное заполнение реквизитов
   - Проведение документа при установленном проценте специалиста
   - Формирование движений в регистрах

### 6.2. Тестирование интеграции с Telegram
1. Создать тестовое обслуживание клиента
2. Проверить появление уведомления в справочнике "УведомленияТелеграмБоту"
3. Нажать кнопку "Отправить изменения в телеграмм" (после записи документа)
4. Убедиться в получении сообщения в Telegram

### 6.3. Тестирование формирования актов
1. Заполнить документы обслуживания за тестовый период
2. Создать документ "РеализацияТоваровУслуг" для договора абонентского обслуживания
3. Выполнить команду "Заполнить"
4. Проверить корректность автозаполнения табличной части

### 6.4. Тестирование планировщика
1. После записи документа "Обслуживание клиента" цветом выделится время, необходимое для выполнения заявки
2. Управление цветами осуществляется через "Категорию"
3. Нажатие на пустую область создает новый документ "Обслуживание клиента"
4. Нажатие на закрашенную область ведет к редактированию документа
5. Для просмотра заданий нескольких пользователей установите галочку "Отображать задачи нескольких пользователей"

### 6.5. Тестирование массового создания актов
**Расположение:** Обслуживание клиентов → Сервис

1. Заполнить документы обслуживания за тестовый период
2. Выполнить команду "Заполнить"
3. Проверить корректность автозаполнения табличной части

|-----------------------------|----------------|-----------------------------------------|

## 8. Расчет заработной платы

### 8.1. Документ "НачислениеЗаработнойПлаты"
**Расположение:** Расчет заработной платы → Важное

**Назначение:** Ежемесячное начисление окладов, процентов от работ и отпускных с автоматическим расчетом НДФЛ.

**Порядок работы:**
1. Создать новый документ "НачислениеЗаработнойПлаты"
2. Нажать кнопку "Заполнить"
3. Система автоматически рассчитает:
   - Оклады (за вычетом дней отпуска)
   - Проценты от выполненных работ
   - Отпускные (если отпуск попадает в расчетный месяц)
   - НДФЛ со всех начислений

### 8.2. Документ "НачислениеФиксированныхПремий"
**Расположение:** Расчет заработной платы → Важное

**Назначение:** Разовое начисление премий с автоматическим расчетом НДФЛ.

**Порядок работы:**
1. Создать документ "НачислениеФиксированныхПремий"
2. В табличной части добавить сотрудников и суммы премий
3. При проведении система автоматически рассчитает и удержит НДФЛ

### 8.3. Документ "ВыплатаЗарплаты"
**Расположение:** Расчет заработной платы → Важное

**Назначение:** Оформление факта выплаты заработной платы сотрудникам.

**Порядок работы:**
1. Создать документ "ВыплатаЗарплаты"
2. Нажать кнопку "Заполнить"
3. Система автоматически заполнит табличную часть списком сотрудников с суммами к выплате

### 8.4. Документ "ГрафикОтпусков"
**Расположение:** Расчет заработной платы → Обычное

**Назначение:** Составление годового графика отпусков для визуального контроля нагрузки.

**Порядок работы:**
1. Создать документ "ГрафикОтпусков", указать год
2. Нажать кнопку "Заполнить" (Система автоматически заполнит табличную часть списком сотрудников)
3. В табличной части добавить планируемые отпуска сотрудников
4. Система автоматически подсветит строки при превышении лимита отпускных дней
5. Для визуального анализа использовать команду "График отпусков"

## 9. Контрольные точки после внедрения

### 9.1. Через неделю:
- Проверить корректность создания документов обслуживания
- Убедиться в работе оповещений через Telegram

### 9.2. Через месяц:
- Проверить формирование массовых актов
- Проконтролировать расчет заработной платы
- Сформировать все предусмотренные отчеты

## 10. Устранение возможных проблем

### 10.1. Проблемы с правами доступа
- Проверить назначение профилей пользователям
- Убедиться в наличии необходимых ролей в профилях

### 10.2. Проблемы с интеграцией Telegram
- Проверить корректность токена и идентификатора группы
- Убедиться в активности регламентного задания

### 10.3. Проблемы с расчетами
- Проверить заполнение условий оплаты сотрудников
- Убедиться в корректности установленных процентов от работ

## Контакты для технической поддержки

В случае возникновения проблем при настройке или эксплуатации системы обращаться к разработчикам по контактам, указанным в документации к доработкам.
